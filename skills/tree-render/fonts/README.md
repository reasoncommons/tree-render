The renderer embeds them in the SVG so it renders anywhere.

Arimo (Regular, Bold) by Steve Matteson / The Arimo Project Authors, free under the SIL Open Font License 1.1 ([OFL-Arimo.txt](OFL-Arimo.txt); no Reserved Font Name), from https://github.com/googlefonts/Arimo (v1.33). Used by the `coggle-exact` style: Coggle sets its text in "Helvetica, Arial, sans-serif", and Arimo is metric-compatible with Arial (and so with Helvetica's widths), which is what Coggle's own PNG export shows. The files here are subsets (Latin, Latin-1 and common punctuation, with kerning) made with fontTools `pyftsubset`, to keep embedded SVGs small.
