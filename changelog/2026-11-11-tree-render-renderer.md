promote: true

The tree-render skill now turns a prepared question or hypothesis tree into a static image for web pages and reports: colour per branch, double-curve tapering branches, and a bold lead with a lighter continuation. The first set is five Wise AI trees (an overview plus Q1–Q4), drawn in an exact reproduction of Coggle's look, now the default style.
