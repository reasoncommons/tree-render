The tree-render skill now turns a prepared question or hypothesis tree into a static image for web pages and reports: colour per branch, thick tapering branches, a bold lead with a lighter continuation, and the "So…" conclusion in red. The first set is five Wise AI trees (an overview plus Q1–Q4), in a default "river" style and a calmer Coggle-like one.
